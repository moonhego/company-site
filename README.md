# スカイラインテクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイラインテクノロジーズ株式会社」の1ページ完結型コーポレートサイトです。
HTML・CSS・JavaScriptを `index.html` 1ファイルにまとめており、ビルドや外部ライブラリは不要です。

> **注意**: 会社名・人名・実績・数字はすべて架空のものです。

## サイトの構成

| セクション | 内容 |
| --- | --- |
| お知らせバー | ナビゲーション直下に最新のお知らせを1件表示 |
| ヒーロー | キャッチコピー「空へ届く、ソフトウェアを。」 |
| 事業内容 | 受託開発 / クラウド・インフラ / AIソリューション / セキュリティ診断 |
| 実績数字 | スクロールで増えるカウントアップ表示 |
| 開発実績 | 架空の事例3件 |
| 会社概要 | ミッションと会社情報 |
| お知らせ | お知らせ一覧 |
| お問い合わせ | デモ用フォーム(実際には送信されません) |

スマートフォンの画面幅にも対応しています。

## ブラウザで開く手順

1. このリポジトリを取得します。

   ```bash
   git clone <リポジトリのURL>
   ```

   すでにフォルダがある場合は、この手順は不要です。

2. `index.html` をブラウザで開きます。次のいずれかの方法で開けます。

   - **エクスプローラーから**: `index.html` をダブルクリックします。
   - **ドラッグ&ドロップ**: `index.html` をブラウザのウィンドウにドラッグします。
   - **コマンドから(Windows)**: フォルダ内で次を実行します。

     ```powershell
     start index.html
     ```

3. ページが表示されれば完了です。
